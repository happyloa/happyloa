## About

I'm a full-stack engineer with 4+ years of experience on enterprise websites, e-commerce, internal systems, and client projects. I work across the stack, from user interfaces and APIs to data, integrations, and deployment. My design background helps me understand users and make complex workflows easier to use.

I've contributed to 50+ delivered projects. Recently I worked on an AI risk-assessment system with role-based access, versioned records, and an offline deployment. I also maintain a [WordPress.org plugin](https://wordpress.org/plugins/site-add-on-watchdog/) and keep shipping releases, bug fixes, compatibility updates, and regression tests for it.

I mostly work with TypeScript, React / Next.js, Vue / Nuxt, Python / FastAPI, PHP / WordPress, PostgreSQL, Docker, and GitHub Actions. I've also used REST APIs, WooCommerce, Cloudflare, Dify, n8n, Elasticsearch, and Qdrant.

## Selected work

### [Site Add-on Watchdog](https://github.com/happyloa/site-add-on-watchdog) · Published WordPress plugin

Monitors installed plugins for outdated versions and security signals, with scheduled scans, a dashboard, and optional notifications. The [public changelog](https://wordpress.org/plugins/site-add-on-watchdog/#developers) lists the follow-up releases: better vulnerability matching, fewer false alerts, sturdier scheduled scans, and more regression tests.

PHP · WordPress · PHPUnit · [WordPress.org listing](https://wordpress.org/plugins/site-add-on-watchdog/) · [Source and changelog](https://github.com/happyloa/site-add-on-watchdog) · [Development notes](https://blog.worksbyaaron.com/posts/site-addon-watchdog-ai-development/)

### AI Risk Assessment System · Client project

I worked on a React, FastAPI, and PostgreSQL application that makes an assessment workflow traceable. It covers role and data-scope permissions, versioned submissions, and a Docker Compose deployment on a network with no internet access. The source code is private, so I wrote up the engineering decisions and production issues in a [development case study](https://blog.worksbyaaron.com/posts/ai-risk-assessment-system-development/).

React · FastAPI · PostgreSQL · Docker

### [Family Album](https://github.com/happyloa/cloudflare-r2-family-album) · Full-stack project

A media library on Next.js and Cloudflare R2, with APIs to upload, move, and delete files. The repository documents the access model, regression tests, CI checks, and deployment.

Next.js · TypeScript · Cloudflare Workers / R2

### [Art Bank](https://artbank.tfaf.org.tw/) · Member frontend

I built the responsive member pages and the API integrations for registration, sign-in state, favorites, and art rental flows.

Nuxt 3 · Tailwind CSS · REST APIs · [Case study](https://blog.worksbyaaron.com/posts/artbank-nuxt3-ssr-development/)
